Various scripts used for plotting things in relation to 
WP4/Dresden experiment simulation results

- DetectorEfficiency_01-06-2026.ipynb
    Large notebook for comparing calculations performed by Sara (OncoRay)
    The notebook includes a lot of documentation not mentioned in this ReadMe
    Plots/calculates/estimates:
        - Effective production efficiency (PGs per proton)
        - Geometric detection probability (PGs striking DE0 area per proton)
        - Estimated count rate (num of hits / time elapsed)
        - Intrinsic detection efficiency (plot/estimates)
        - XCOM data using the atomic composition of M600
        - Intrinsic detection efficiency for a Na-22 source
        - Various plots supporting the data

- EnergyTimeForWP4.ipynb
    Unfinished/in development
    Plots time distribution of gamma-ray/neutron hits
    Also plots time-energy distribution (heatmap)
    Only preliminary investigation performed


- PlotsForWP4_250226.ipynb
    Plots for WP4/NOVO-meeting in February
    Plots some erranous spectroscopy plots and
    estimates count rates in the scintillator bars


- PlotsForWP4_310326.ipynb
    Plots various data for Dresden experiment runs 
    NOVO51 (+-0 mm), NOVO139 (-167 mm) and NOVO140 (+183 mm)
    Plots include: 
        - Energy deposition distributions (histograms)
        - Gamma-to-neutron ratios
        - Particle rates
        - 2FN / 3PG rates
        - Initial investigations into deadtime effects
        - 
    NB: Shifts for these simulations were reversed

- PlotsForWP4_170426.ipynb
    Plots the Dresden experiment measurement data in the same style
    as the simulation data.
