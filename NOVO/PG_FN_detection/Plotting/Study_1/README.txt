Plotting notebooks for Study 1

- Study1_Figure_2FN_3PG.ipynb
    Scatter plot of the number of coincidence events per energy per patient case
        - Double coincidence gamma-ray events
        - Triple coincidence gamma-ray events
        - Double coincidence neutron events
    Uses pre-postprocessed hit data (hit_txt_file_reader_v01)


- Study1_Figure_CountRate.ipynb
    Scatter plots of (singular) hits per scintillator bar per patient
        - Gamma rays
        - Neutrons
        - Both
    Uses pre-postprocessed hit data (hit_txt_file_reader_v01)


- Study1_HitSpectroscopy.ipynb
    Histogram plots of mainly gamma ray energy depositions
    Also includes some neutron energy deposition histograms
    Uses pre-postprocessed hit data (hit_txt_file_reader_v01)


- Study1_LayerImportance.ipynb
    Plots several plots:
        - Layer scatter combinations (heatmaps)
        - Plots on how additional layers affect 
          the numbers of detected 2PGs, 3PGs and 2FNs
