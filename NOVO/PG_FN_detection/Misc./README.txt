- get_counters_from_h5.py
    A script made in correlation with the software ngimager 
    by Hunter (HVL/Haukeland). ngimager prints diagnostics 
    (counters) with information on where/why hits/events are "lost"
    These counters are saved in the h5 output file.

    This script extracts this data from an ngimager file 
    and prints them into a .txt-file
